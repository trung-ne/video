PROJECT ORGANIZATION
────────────────────
Each video goes into:
  projects/video-XXX-topic/
  ├── idea.txt           ← Your original idea
  ├── transcript.txt     ← Script/narration
  ├── timeline.json      ← Generated events (editable)
  ├── output.mp4         ← Final rendered video
  └── metadata.json      ← Status & version tracking

QUICK START
───────────
1. npx ts-node scripts/new-project.ts --idea "Your topic"
   → Creates projects/video-001-your-topic/

2. Write transcript in projects/video-001-your-topic/transcript.txt

3. npx ts-node scripts/generate-timeline.ts --project video-001-your-topic
   → Generates timeline.json via Claude AI

4. npm start
   → Open http://localhost:3000 to preview & edit

5. npx ts-node scripts/render.ts --project video-001-your-topic
   → Renders output.mp4

6 CRITICAL RULES
─────────────────
1. HOLD STATE — Assets don't disappear unless explicitly removed
2. POSITION GRID — Use standard x/y coordinates for consistency
3. TIMING — 1 Vietnamese word ≈ 7 frames; enter 10-15 frames early
4. ANIMATION — Use semantic animation types (popIn, slideLeft, etc.)
5. CAMERA — Zoom 1.2-1.5 to focus, reset 1.0 between topics
6. SCENE STRUCTURE — Intro → Concept → Buildup → Climax → CTA
